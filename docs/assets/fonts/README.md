# Display font

Noto Serif SC, weight 600; SIL Open Font License (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc

Self-hosted Google Fonts subset for the current h1, h2 and blockquote text. Regenerate the subset when that text changes. No runtime request to Google. Body text uses local system fonts.
