# 陪伴，从听见开始：项目站设计

2026-11-04。用户要求自主重设计；用途是让课程老师、同学和接入开发者理解项目、探索机制并找到代码与证据。产品事实见根目录 PRODUCT.md；此文只约束公开项目站。

## 叙事与视觉

模式：Experience + Read。入口以一段“只想被听见”的合成对话展开，随后允许读者改变意愿，观察同意、拒绝和反馈怎样改变执行。沿着交互体验、压力研究、策略目录、系统职责、关系记忆、实测与运行入口深入。研究来源与长协议可展开，保持首轮阅读轻快。

视觉采用课程展览中的双声部叙事：用户听见的在前，幕后责任在旁。暖赭色大面积入口与纸白正文呼应日常陪伴；深绿架构和棕色运行区标记阅读层次。真实中文内容、自托管宋体标题、开放式策略列表与机制连线承担识别度，不使用虚构设备照片。

Impeccable 设计参考、craft floor 与工具检查已使用；emil-design-eng 用于状态切换、可中断演示、键盘和减少动效。context 初次因缓存权限失败，改为直接读取项目资料；引擎随后在本工作副本忽略目录中安装。concept-seed 参考 `seed:63f77a4dc9591217`；用户授权自主设计，未要求用户逐项选择。方向比较考虑研究展板、生活日记、双声部对话、课程刊物、校园导视、关系地图与实验记录；选择双声部。候选的积木顺序说明容易误示真实通路完全串行，陶艺烧制不符合产品机制，均不采用；吸收独立步骤清楚、整页色彩一致的要求。代码直接实现，未生成页面效果图。受本侧会话禁止子代理的约束，最终由本线程按独立复核顺序审阅，未声称有独立代理评审。

## 设计约定

- 颜色：纸白 `#f6f2e9`、暖赭 `#e9bc69`、正文 `#302d27`、棕 `#713e2d`、绿 `#41624f`、深绿 `#2b342c`。检测器的cream-palette提示保留为有意选择：全文还有赭、深绿、棕三块区域，不把中性色当作全部设计。
- 标题：Noto Serif SC 600，仅打包当前标题和引用的115字符子集，21,572字节，附OFL。正文为本地中文无衬线字体；运行时不请求Google。
- 字阶：正文16px，长说明14–16px，辅助内容至少12px；h1最高82px，h2最高48px。窄屏标题31–42px；信息不靠字号缩小到不可读来塞入。
- 组件：导航、三态演示选择、双栏对话、原生details协议列表、条件select、P50/P90按钮组。用线与留白分组，详细资料渐进展开。
- 交互：aria-pressed标记选择，原生details/select保留键盘行为；aria-live报告对话和加载结果；提供跳到正文与可见焦点。交互控件至少44px高；主要按钮52px。
- 动效：只在指针切换情境时使用230ms的5px位移与透明度；键盘切换不做位移动画。主动演示每步1050ms，可暂停、切换、重置；页面隐藏自动暂停。reduced-motion直接展示判断，不自动计时。

## 内容边界与维护

页面对话是静态合成机制演示，不调用模型，不输入私人对话。后台演示按顺序解释职责，不表示真实通路串行等待。三种情境对应Core/StateMachine、StrategyCatalog、Cognition与MemoryService现有语义。Action示例明确假设候选已经评审和校验，执行前仍需点击许可。

目录仍读取 `assets/project-data.json`，保留六策略、三练习与16来源。页面筛选只是压力/路径映射，真实适用条件以运行系统为准。指标来自既有VALIDATION.md的voice-final2；2026-11-04记录保持原样。本次改版未重跑后端或真实API验收。P50/P90图是累计分位数，条带作差只为说明时间位置，不能当作单样本耗时或真实设备首响。

保留分层机制PNG、五张源码交互图以及v1/v2历史页。图内源码固定提交不变；首页文档链接仍绑定project-data.json中的已提交版本。

编辑 `index.html`、`assets/project.css` 和 `assets/project.js`。颜色和间距由CSS变量集中管理，脚本不依赖框架。策略变更后按docs/README刷新数据；标题或引用增字时刷新字体子集。加载失败显示重试与仓库备用链接，演示不依赖目录加载成功。站点没有分析跟踪或后端凭据。
