# 课程项目站设计与维护

模式：Redesign · Overhaul。面向课程老师和同学，阅读距离以笔记本与手机为主。采用研究手册式信息编排：问题、证据、具体策略、运行链路、验证；保留旧 v1/v2 图文件与入口，不改变已公开专题图地址。没有表单、分析追踪或联网模型调用。

设计读取：信息架构 / 温和技术说明；变化5、动效2、密度7、素材依赖2、既有风格保留6。具体体现为两列章节与单栏长文交替、只在交互反馈时过渡、细节折叠、源码图与真实数据承担视觉、沿用青绿/深墨色。

颜色：深墨 `#18343b`（文字/深色机制区）、青绿 `#12675e`（动作/选择）、纸白 `#f2f5f3`（页面）、白色（内容）、棕色 `#815322`（限制）。标题为本机宋体类字体，正文 Microsoft YaHei/PingFang SC，代码Consolas。8px间距基准，正文18px，标题clamp自适应；内容最大宽1180px，控件至少44px。细线分隔，8px小圆角，除浮动导航外不使用阴影。过渡140ms，尊重reduced-motion。

来源：研究文字来自核查报告的原创归纳；策略数据由 `scripts/build_project_site.py` 从版本化YAML提取，原始研究链接保留。页面不使用想象的设备照片或未经授权的肖像。验证数字由独立的公开汇总文件提供，待验收项明确标注，不从历史数字推算。

维护：编辑 `docs/index.html` / `docs/assets/project.css` / `docs/assets/project.js`；运行构建脚本刷新 `project-data.json`。架构图使用archify候选与finalize生成，不手改HTML。旧图库在 `index-v1.html`、`index-v2.html`。验收使用ego-browser，实际核验CSS视口宽1600、1422、853和390px（浏览器缩放会改变请求的设备宽度）、筛选空集、详情展开、键盘和资源。源码引用应固定到最终实现提交。
