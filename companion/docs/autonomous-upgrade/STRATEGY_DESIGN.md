# 从研究证据到可执行支持

版本：course-1.0，2026-11-04。研究依据见 [EVIDENCE_REVIEW](research/EVIDENCE_REVIEW.md)。六项支持、三段练习已进入 development 主路径；课程回执course-release-1已绑定逐项工程与真实回放证据。部署副本完成固定音频准备后实际demo准入通过。`enabled` 仍只表示来源与自动核查状态；demo会另外验证当前摘要与实际音频。见QUALITY_REVIEW及VALIDATION。

## 内容分工

五类压力是本项目可重叠的工作标签，四条路径是对话线索。它们不是诊断，也不是已经证明的致病模型。原研究中人工课程、八周干预或成年人的书写实验，只支撑机制借鉴，不证明这里的几句语音有同样效果。

| 内容 | 承载位置 | 运行职责 |
| --- | --- | --- |
| 尊重自主、低评判、AI 身份、现实关系 | persona / Talker / OutputRail | 所有状态适用；不依赖检索相似度 |
| 倾听、安慰、许可、安静、结束 | stages / StateMachine | 可以停在任一阶段；结束不要求行动承诺 |
| 六项可选支持 | cards / StrategyCatalog | 本地先过滤，后台 Planner 选一个焦点；Critic 核查同一内容摘要 |
| 短练习 | exercises / ExercisePlayer / OutputPort | 明确许可后确定性播放，含停顿，实际总长≤90秒，随时取消 |
| 风险与危机 | RiskDetector / Core / crisis | 独立识别、固定接管，模型不能解除；不自动通知别人 |
| 来源文献 | research / content_manifest | 离线核查、版本追溯；不每轮联网，不投喂论文全文 |
| 用户反馈与关系记忆 | Interactions / MemoryService / Store | 保留具体来源、范围及更正；不把播放结束当作有益 |

采用结构化目录而非向量库：当前六个条目，匹配需要严格的上下文排除；中文关键词只在合格集内排序。没有合适项时保持倾听或澄清一个必要信息。关键词不授予行动权限。

## 覆盖和选择

| ID | 压力/共同路径/障碍 | 关键机制、最少信息 | 排除与替代 | 证据 |
| --- | --- | --- | --- | --- |
| S16 | 学业、反复想，可处理混合压力中的一个片段 | 从抽象评价转具体片段，分出自己能影响的一步；已经说清的细节不再追问 | 强情绪、只想说、不安全关系或创伤细节：倾听/安全支持 | E06、E08 |
| kind_self_talk | 自我压力、社会评价、自我批评 | 区分一次表现与整个人的价值；温和自我对话和朋友视角合并 | 不强迫积极肯定、不评论身材；外部伤害不改写成用户想法错误 | E07、E09 |
| safe_communication | 关系误会/冲突 | 用户愿意表达且明确对象相对安全；练一句感受与请求 | 欺凌/威胁、无隐私、睡前：不劝对质/和解，转安全支持或结束 | E10、E05 |
| safe_support | 孤独、各类压力中的求助障碍 | 澄清评价/隐私/负担/安全顾虑，由用户选择一个现实入口 | 不默认家长/老师安全；拒绝不反复推；危险由安全通路接管 | E04、E05、E13 |
| values_exploration | 未来迷茫、选择压力 | 从已表达的兴趣/在意之事选一个暂时想了解的问题 | 不给选科/录取政策结论，不做职业测评，不逼迫确定人生方向 | E11、E01 |
| worry_parking | 睡眠、睡前反复想 | 用户明确休息时机且愿意留一句担心，然后收尾 | 不延长为任务清单，不做睡眠限制/刺激控制治疗，不保证入睡 | E12、E02 |

六类并非压力×路径的穷举。混合情境先尊重本轮意愿，再选一个焦点。例如“父母因排名骂我”可同时标学业、评价、关系；只有对象安全且用户想沟通时才用 safe_communication。遭威胁时不因“关系”关键词推荐沟通。只想被听见、拒绝、换题、安静或结束也都是有效支持结果。

每项 YAML 包含版本、来源、机制、改编限制、最低信息、前提、排除、负担、许可、步骤、中文例子、反例、禁语、退出及反馈解释。这里只列总映射，实际步骤以配置为准。

## 合并、暂缓与历史处理

- 将具体加工与“可控的一小步”放进 S16 的单一流程，不额外建同义“问题解决”“反刍切换”卡。S16 从旧夹具更新为 course-1.0；旧日志中的内容没有被改写，旧计划缺内容版本时保持历史未知。
- 朋友视角、双重标准与温和自我对话合并为 kind_self_talk，避免在同一轮连续换招。
- safe_communication 与 safe_support 保持分开：前者要求已有安全对象，产物是一句可选表达；后者允许尚无安全对象，产物是用户选择/拒绝的支持入口。两者不能混作“劝找家长”。
- 社交小尝试归入 safe_support 的低负担开口，不单独建立“归属感正常化”或“说即相信”练习。没有证据时不说“大家都这样”，也不让用户替系统说服自己。
- 生涯叙事与价值小行动合并为 values_exploration；不增加测评、评分或政策建议功能。
- 不实施完整 CBT-I、IPT-A、自动诊断、专业暴露、睡眠限制或“协同心态一定让成绩提高”等措施。短支持不继承完整人工干预效果。
- 缺失的 A 线策略全文没有恢复；S03–S15/S17–S19 不猜测含义，不把新条目伪装成原材料。S1/S2 作为阶段/通用原则的概念映射保留；S20 的危机概念由独立固定通路承接。

## 准入与验证方法

`content_manifest.yaml` 分开记录来源核查和 Codex 自动内容审查，保留读取范围、对象、限制和内容摘要。它不声称人工或临床审查。demo 还要求逐项适用/排除/许可拒绝/退出/反馈证据、真实模型场景、未过期的内容与提示词摘要、音频存在和实际时长。

新内容的自动核查和当前确定性证据在 `test_course_strategies.py`：逐项检查筛选，并通过真实 Core/FakeLLM 角色协议完成邀请、同意、对应步骤、负面反馈、支持经历和退出。该测试有意限制候选以覆盖每个条目，不是自然选择成功证据。最终自然选择与真实模型目标覆盖须分别报告。

原固定 17 张卡的断言已替换为完整课程内容回执。旧“无卡等待”的测试显式提供 medium readiness，保留有效许可和等待语义；OR 目标匹配测试显式构造空压力侧，避免依赖旧 S16 的特殊字段。这些变化保留原业务规则。

本地 `artifacts/autonomous-upgrade/live-debug1` 是首轮调试失败记录：Analysis 省略路由字段、Critic 混淆 verdict 与 issue code，导致没有执行行动。已针对契约提示修复，继续真实复测；该调试不作为最终准入依据。
